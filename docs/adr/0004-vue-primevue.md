# ADR-0004. Фронт на Vue 3 и PrimeVue 4.5 (MIT)

- Статус: принято; выбор UI-библиотеки на будущее — задача этапа 0
- Дата: 03.11.2026

## Контекст

Нужен фреймворк с официальным роутером и стейтом, понятный бэкенд-разработчикам на C#, и UI-библиотека с мощной таблицей (Э-04, Э-07, Э-12) и темизацией под дизайн-систему «ЛБ Ломбард».

С версии 5 PrimeVue распространяется под PrimeUI License: бесплатно только для организаций с выручкой до $1 млн, до 5 разработчиков и до 10 сотрудников, иначе — платная лицензия на разработчика; без ключа показывается плашка о лицензии.

## Решение

- Vue 3 + TypeScript + Vite, Vue Router, Pinia, vue-i18n.
- PrimeVue закреплён на 4.5.5 (последняя версия под MIT) вместе с `@primeuix/themes` 2.0.3 и `primeicons` 7.0.0.
- Страница должника — отдельная сборка без UI-библиотеки.

## Варианты на будущее (решить на этапе 0)

1. Остаться на PrimeVue 4.5.5 — бесплатно, но без новых версий и исправлений.
2. Купить коммерческую лицензию PrimeVue 5 на разработчиков фронта.
3. Перейти на MIT-библиотеку (Naive UI, Element Plus, shadcn-vue / Reka UI) — чем раньше, тем дешевле.

## Последствия

Компоненты PrimeVue оборачиваем в `src/shared/ui`, чтобы замена библиотеки затрагивала обёртки, а не экраны.
