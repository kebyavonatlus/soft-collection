# ADR-0003. Только PostgreSQL

- Статус: принято (подтвердить с пилотом на этапе 0)
- Дата: 03.11.2026

## Контекст

Банки часто используют MS SQL Server. Поддержка двух СУБД примерно удваивает работу с базой.

## Решение

Поддерживаем только PostgreSQL 16 в контейнере, поставляемом вместе с модулем. Пользуемся его возможностями: декларативное секционирование, триггеры append-only для аудита, COPY для импорта.

## Последствия

- Требование «PostgreSQL в контейнере» фиксируется в требованиях к серверам.
- Если пилот — банк с жёстким требованием MS SQL, решение пересматривается до начала S1.
