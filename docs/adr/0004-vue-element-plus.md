# ADR-0004. Фронт на Vue 3 и Element Plus

- Статус: принято
- Дата: 03.11.2026

## Контекст

Нужен фреймворк с официальным роутером и стейтом, понятный бэкенд-разработчикам на C#, и UI-библиотека с мощной таблицей (Э-04, Э-07, Э-12), календарями, формами, кыргызской локалью и темизацией под дизайн-систему «ЛБ Ломбард».

Сначала был выбран PrimeVue. С версии 5 он распространяется под коммерческой PrimeUI License: бесплатно только для организаций с выручкой до $1 млн, до 5 разработчиков и до 10 сотрудников, иначе — платная лицензия на разработчика; без ключа на экране висит плашка о лицензии. Последняя версия под MIT (4.5.5) больше не развивается. Слезать с библиотеки тем дороже, чем больше экранов на ней написано, поэтому решение пересмотрено сразу, на каркасе.

## Рассмотренные варианты

| Вариант | Лицензия | Плюсы | Минусы |
|---|---|---|---|
| **Element Plus** | MIT | Самая распространённая UI-библиотека для Vue 3 в корпоративных приложениях; таблица с выбором строк, сортировкой, фиксированными колонками и виртуальная таблица; встроенная локаль `ky`; темизация через CSS-переменные | Внешний вид по умолчанию приходится подгонять под макеты |
| Naive UI | MIT | Хорошая типизация, локаль `kyKG`, темизация через объект темы | Меньше сообщество и поддерживающая команда |
| shadcn-vue (Reka UI + Tailwind) | MIT | Код компонентов живёт в репозитории — зависимости от вендора нет | Таблицы, календари и формы собираются вручную; нужен Tailwind — дольше для команды на C# |
| Vuetify | MIT | Зрелая, полная | Material Design, далеко от макетов |
| PrimeVue 5 | Коммерческая | — | Платная лицензия на каждого фронтенд-разработчика |

## Решение

- Vue 3 + TypeScript + Vite, Vue Router, Pinia, vue-i18n.
- **Element Plus** (MIT) — UI-библиотека; **Lucide** (`@lucide/vue`, ISC) — иконки (те же, что на макетах).
- Токены «ЛБ Ломбард» задаются CSS-переменными в `web/src/theme/element.css`.
- **Граница с библиотекой:** экраны используют только обёртки `Sc*` из `web/src/shared/ui`. Прямой импорт `element-plus` за пределами `src/shared/ui` и `src/theme` запрещён правилом ESLint `no-restricted-imports` — сборка CI падает.
- Страница должника — отдельная сборка без UI-библиотеки.

## Последствия

- Если Element Plus сменит лицензию или перестанет развиваться, переписываются только обёртки в `src/shared/ui`, а не экраны.
- Обёртки задают и правила ТЗ: одна синяя кнопка на экране (`variant="primary"`), недоступная кнопка — серая с причиной в подсказке (`disabledReason`).
