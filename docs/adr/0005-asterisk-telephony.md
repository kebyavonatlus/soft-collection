# ADR-0005. Телефония на Asterisk

- Статус: принято, подтвердить спайком этапа 0
- Дата: 03.11.2026

## Контекст

Нужны звонок в один клик из браузера, запись разговора, фраза о записи на языке клиента, позже — автообзвон и голосовой робот. Установка у клиента; у банка может быть своя станция.

## Решение

- Asterisk 20 LTS в контейнере: PJSIP + WebRTC для браузера (JsSIP), SIP-транк оператора наружу.
- Управление вызовами из бэкенда через ARI (свой тонкий клиент на C#).
- Запись — MixMonitor, файлы шифруются и хранятся в MinIO, срок хранения — 12 месяцев (настройка).
- У банка — подключение к его станции по SIP через тот же `ITelephonyProvider`.
- Фразы робота на кыргызском и русском склеиваются из записанных фрагментов, синтез речи не используем.

## Последствия

- Нужны договор на SIP-транк и тестовый номер уже в этапе 0.
- WebRTC требует HTTPS/WSS и сертификат во внутренней сети организации.
