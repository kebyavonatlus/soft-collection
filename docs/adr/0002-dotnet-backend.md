# ADR-0002. Бэкенд на .NET 10

- Статус: принято
- Дата: 03.11.2026

## Контекст

Открытый вопрос ТЗ (раздел 11) — стек. Команда пишет на C#.

## Решение

.NET 10 LTS, ASP.NET Core. EF Core для обычных операций, Dapper/SQL для пересчёта и отчётов, Hangfire (PostgreSQL) для фоновых задач, SignalR для реалтайма.

Не используем библиотеки с коммерческими лицензиями: MediatR, AutoMapper, MassTransit, QuestPDF. Обработчики и маппинг пишем явно.

## Последствия

- .NET 10 поддерживается до ноября 2028; переход на следующий LTS — плановая задача.
- Хосты работают в Linux-контейнерах; Windows Server у банка не обязателен.
